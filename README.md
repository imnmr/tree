# tree

Tree visualization program.

## Building

To build the program, you would need the Odin compiler (version dev-2026-11 or higher) as well as [MSVC for machines running on Windows](https://odin-lang.org/docs/install/#windows).
Get the source code and execute the following command to run the program:

```
odin run -file main.odin
```

Or, to compile the program into an executable file:

```
odin build . -out:tree.exe
tree.exe
```
